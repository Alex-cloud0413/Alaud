# Watch 最近使用入口旧图标排查

日期：2026-10-25；版本：0.2.0 (3)。

## 现象和当前判断

用户反馈：Watch 的 App 列表显示新版黑白图标，按 Digital Crown 出现的最近使用入口仍显示旧图标。此现象来源为用户反馈，未独立取得两处界面的前后截图。重启后的视觉验收采用用户明确回报（user_report），与资源检查分开记录。

已核对：

- 通过 devicectl 回读手表安装版本为 0.2.0 (3)，与本次黑白图标构建一致。
- Watch 图标目录的 16 个图像槽位全部存在，逐像素检查 RGB 三通道相等，均为黑白灰。
- 同一构建的 Assets.car 列举出对应 16 个 Icon Image，`assetutil --validate-file` 确认全部图像块和多尺寸图标类有效；主图标名为 AppIcon。
- Device Hub 的 View Screen 显示启用开发者模式提示，但 devicectl 设备详情明确返回 enabled、paired、tunnel connected；不要因此反复要求用户切换开发者模式。

资源未发现漏换。正常重启后，用户确认最近使用入口已显示新版图标，支持 watchOS 图标缓存未刷新这一判断；没有独立定位系统内部根因。App 没有用于清空系统最近使用图标缓存的公开配置项。

## 处理顺序与停止条件

1. 先确认录音已经结束，再尝试正常重启 Watch；重启后由用户解锁。重启会中断活动录音，不能在未确认时执行。
2. 打开 Alaud，再回到用户报告的最近使用入口核对图标。以真实界面或用户明确回报为验收依据；版本回读不能替代视觉验收。
3. 若仍是旧图标，再核对原地更新行为和系统图标缓存；不先卸载 App、不更换 bundle ID、不删除任何录音，也不直接清理系统缓存目录。

## 处理结果

用户确认录音已经结束并允许重启后，通过 devicectl 请求完整正常重启，命令成功返回。随后用户按提示重启后解锁、打开 Alaud 并检查最近使用入口，明确回复「已显示新版图标」。

验收状态：user_report_passed。没有重新构建、卸载、更换 bundle ID、修改图标资源或手动删除录音。安装版本保持 0.2.0 (3)。
