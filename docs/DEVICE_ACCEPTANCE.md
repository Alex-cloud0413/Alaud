# 真机验收清单

状态：部分通过。2026-10-25 用户反馈，手表真实录音、同步到手机和转写已实现（user_report）；0.1.1 Watch 清理已通过真机核验；0.2 iCloud 跨 Mac / iPhone 合成恢复、手机既有录音云迁移及本地释放已通过。多人长会议、续航与异常恢复仍待执行。模拟器与合成音频测试不替代这些验收。

## 开始前

- iPhone、Watch 与 Mac 均安装 Alaud；手机和 Mac 使用同一 iCloud 账号并开启 iCloud Drive，首次打开并同意麦克风权限。
- iPhone 设置中准备中文离线转写模型；可用性取决于设备与语言支持。
- 重要测试对话应让参与者知情；先以无敏感内容的测试语料验证。

## 录音与入口

- 分别在手机、手表界面开始/暂停/继续/结束，确认状态与原音一致。
- 在快捷指令里运行开始和结束；将切换动作绑定到设备支持的操作按钮，检查冷启动及锁屏行为。
- 每端分别录制 90–120 分钟；熄屏、回表盘、切换 App，回听片段边界。
- 记录起止电量、发热、可用空间及每个原音片段的时长。

## 会议收音

5–10 人，手腕自然放置，对比近端、远端、交叉发言、桌面摩擦与空调噪声。人工逐项核对关键待办是否被清楚录下；没有听清的信息不能由摘要补全。

## 同步与异常

- 关闭配对连接录制，结束后恢复连接，确认手机最终得到全部片段。
- 音频传输中杀死/重启两端 App，确认原音仍在、重试不生成重复会议。
- 来电横幅、全屏来电、实际接听、Siri、闹钟分别测试；确认中断记录和恢复行为。
- 手表/手机空间不足时确认可见错误，并保留已有原音。
- 正在录音时强制结束 App，重开后确认恢复的片段和缺口提示。
- 结束并完整同步后，手机可回听（云端确认后需按需下载），手表原音及会议目录自动删除；断线、缺片或校验失败时不得删除。

## 会后与导出

- 进行中文真实语音转写，核对人名、专有名词和时间点；中途退出后继续。
- 对未全部同步的会议不开始转写；已完成但未识别出文字时保留原音。
- 手机修改标题/备注/待办后再次收到手表重传，不覆盖编辑。
- 导出 Markdown/JSON 与原音，对比设备中的原文和 SHA-256。

## 0.2 三端与 iCloud 待验收

- 在 Mac 主动录音并准备转写模型，核对手机显示和按需回听。
- 小时级会议上传；断网、iCloud 空间不足、App 被中止时保留原件，恢复后能补齐并清理。
- iPhone / Mac 同时修改标题、备注、待办，核对合并；已释放的原音离线时正确提示。
- 播放或转写期间同步与释放缓存，确认正在使用的音频不中断。
- 账号切换不把旧库自动传入新账号；仅在有完整独立备份的测试账号验证。
